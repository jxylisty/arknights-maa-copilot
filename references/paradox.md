# 悖论模拟（mem_ 关）

干员详情页里的单人模拟战，阵容固定（自己+剧情组），**不需要选人、不耗理智**。
MAA v6.20 有专门的 **ParadoxCopilot** 任务链，体验比普通 Copilot 更顺。

## 入口与找目标

- 游戏侧导航：主界面 → 「干员（角色管理）」→ 干员列表右上角
  **「悖论模拟」筛选 (1613, 68)** → 只显示有悖论的干员，
  「未通过」= 已解锁未通关（优先打这些）→ 点干员卡片进详情页（左下角大字是干员名）。
- 筛选列表里名字被「未通过/未解锁」标签挡住，OCR 读不出，直接点卡片看详情页最可靠。
- stage code 规律：**`mem_<干员id>_1`**（林 = `mem_lin_1`、桃金娘 = `mem_myrtle_1`）。

找作业：`levelKeyword=mem_` 翻页拉全量，再按作业标题里的干员名对着
`load_box()` 匹配自己有的干员，比逐个猜 id 快：

```python
import copilot_api as CA
rows = CA.search_stage("mem_lin_1")   # 或 levelKeyword="mem_" 翻页全量再按名字匹配
# 悖论作业一般只声明干员名+技能号，练度要求几乎不设，feasible 基本必过
```

**失败多半是作业本身不稳**：重试一次，连败 2 次就换作业。

## 关键流程：停在技能弹窗，让 MAA 点开始

MAA 的 `BattleStartSimulation` 模板（roi [955,86,136,606]@1280）匹配的是
**技能选择弹窗右侧的竖向「开始模拟」箭头**。所以 MAA 要求游戏停在技能弹窗。

**千万不要手动点进战斗再启动 MAA**——进了战斗按钮就没了，
`BattleStartAll` 重试 3 次后 `任务出错: 悖论模拟`，战斗没人操作空跑送死。

正确顺序（坐标 1920×1080）：

1. 悖论详情页点「开始模拟」**(1765, 990)** → 弹出技能列表
2. 点作业要求的技能：S1 **(900, 255)** / S2 **(900, 545)** / S3 **(900, 830)**
3. **停住**，交给 MAA：

```python
import maa_drive as M
w = M.win()
M.tab_click(w, '自动战斗')
with M.keep_focus():
    M.set_path(w, r'...\config\copilot\mem_lin_job_47079.json', settle=2.0)
M.set_checkbox(w, '自动编队', False)   # 悖论阵容固定，编队无意义
M.set_checkbox(w, '多作业模式', False)
M.click_start(w)                        # MAA 自己点「开始模拟」并接管战斗
```

4. MAA 下发完全部动作后任务链就结束（`完成任务: 悖论模拟` ≠ 战斗结束），
   **OCR 轮询屏幕**等 `任务失败` / `行动结束` / 回到悖论详情页。悖论战斗 1–3 分钟。
5. 通关判据：悖论详情页左下角变「**已完成模拟作战**」。
6. 失败恢复：失败画面点屏幕 → 「行动结束」结算页点屏幕 → 回悖论详情页
   （2–3 下 (960,540)），从第 1 步再走一遍。

  战斗空跑失败；第二次停在技能弹窗交给 MAA，一次通过。
- 真言 mem_mantra_1，作业 106252（S3，精二1级/7级）：停在技能弹窗交 MAA，一次通过。
- 伊桑 mem_ethan_1，作业 26206（S2，作者自述「捆人看脸，漏了就刷几次」）：
  第 1 次失败，自动重试第 2 次通过。**不稳定的作业直接写重试循环**：
  失败恢复（点屏幕回悖论页）→ 重开，比换作业省事。
- 干员列表「悖论模拟」筛选里名字被「未通过/未解锁」标签挡住，OCR 读不出，
  直接点卡片进详情页看名字（左下角大字）最可靠。
- 悖论详情页 back 先回干员属性页，再 back 一次才到列表（共两层）。
- 坐标复用有风险：列表页右上 (1613,68) 是「悖论模拟」筛选，但同样的坐标在
  别的页面可能是别的入口（误点进过采购中心）——点之前先截图确认当前页面。
