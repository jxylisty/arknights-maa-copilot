## 干员升级（已实测：伺夜 Lv1 → 12）

**流程**：主界面「干员·角色管理」→ 点干员卡进详情页 → 等级圆环旁的 **+** →
升级页（转轮设目标等级，自动配 EXP 材料）→ **确定** → **提升等级** →
toast「干员等级提升！」。

| 页面 | 元素 | 坐标 |
|---|---|---|
| 主界面 | 干员（角色管理） | (1540, 520) |
| 干员列表 | 等级排序切换（升/降序） | (1300, 60) |
| 干员列表 | 卡片网格 | 7 列，卡宽 ~206px、列距 ~257px；首卡 (37-243, 127-600)，第二行 y 从 640 起 |
| 详情页 | 等级 + （进升级页） | (1837, 210) |
| 详情页 | 精英化 + / 技能升级 + | (1505, 410) / (1805, 600) |
| 升级页 | 等级转轮（快速下甩） | swipe (1390,260)→(1390,680) ms=280 ≈ +11 级 |
| 升级页 | 确定（确认材料选择） | (1770, 737) |
| 升级页 | 提升等级（执行） | (1789, 905) |
| 升级页 | 重置 | (1786, 130) |

要点：

- 转轮快甩一格 ≈ 11 级，甩完用 OCR 读 `目标等级 LV N` 校准；材料是自动选的，
  确定 之后还要再点 **提升等级** 才真正生效（两段式，别在第一步就当成功）。
- 成本：EXP≈等额 LMD 的一半；Lv1→12（6★）只花 2200 龙门币 + 高级×1 + 基础×1。
- 成功判据：详情页 LV 数字变化 + 龙门币扣减，别看动画。
- 干员列表默认按等级**降序**（90 级在前）；点「等级」翻成升序可以把没练的 6★ 排前面。
- 升级页底部圆圈是材料库存（高级/中级/初级/基础作战记录、龙门币）。

## MAA「一键长草」任务队列（冒烟测试通过）

`一键长草` tab = MAA 的日常自动化。任务勾选框：
`开始唤醒` `基建换班` `理智作战` `自动公招` `信用收支` `领取奖励` `自动肉鸽` `生息演算`，
其中基建换班带子选项（`制造站/贸易站/控制中枢/发电站/会客室/办公室/宿舍/加工站/训练室/回收站/副手换人`）。
总开关是 Button **`Link Start!`**。

驱动方式（全部经 `maa_drive.py`，不抢焦点）：

```python
import maa_drive as M
w = M.win()
M.tab_click(w, '一键长草')
M.set_checkbox(w, '领取奖励', True)      # 按需勾任务
# 找到文本含 'Link Start' 的 Button，keep_focus() 里 invoke()
# 进度盯 gui.log：『开始任务: X』/『完成任务: X (用时..)』/『Completed Task Chain: X』
```

实测（只勾 开始唤醒+领取奖励）：StartUp 链 4 秒完成，Award 链随后自跑。
**注意事项：**

1. **MAA 退出时用当前 UI 状态覆写 gui.json**——动勾选框之前先把原状态全部
   `checkbox_state()` 存下来，测完逐项恢复，否则用户的日常配置会被洗掉。
2. 队列运行期间 MAA 完全接管模拟器，adb 别同时发指令。
3. 判完成要看 `Completed Task Chain: Award`；「开始任务: X」只是开始，
   和上一条的「完成任务」同帧出现会造出假阳性（踩过）。
4. `Link Start!` 之前队列里勾了什么就跑什么——**全选状态下按下会连肉鸽一起跑**。
